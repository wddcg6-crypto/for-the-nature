# 从收藏图提炼的设计规则

## 证据与参数的界限

本库于 2026-10-20 审阅 IMG_3030–3049 共 20 张截图。截图包含图面、配色讲解、社交水印、少量文献信息；不是论文原始矢量文件。**观察**是画面中可见的关系；**建议**是把关系转化为新图的选择；**实现起点**是便于落地的可调参数。三者不要混淆。

## 1. 颜色承担语义

观察：3030 的粉/青贯穿分布、蛋白结构和柱状比较；3036 每个方法在原始曲线和残差中同色；3040、3049 在总览与构成图中沿用类别颜色。这比选“好看”的颜色更有复用价值。

建议：先建全图唯一的 `group -> color` 映射，面板只取子集，不重新循环色板。处理缺失类别时不要让后续类别换色。合并为 Others 的类别显式说明合并规则，灰色可作为 Others 的起点。

区分四种映射：

| 数据语义 | 处理方式 | 参考与限制 |
|---|---|---|
| 无序类别 | 相异色相，必要时辅以形状/文字 | 3039 的棕红蓝绿、3049 的红青深蓝；红绿组合需要冗余编码 |
| 有序连续强度 | 检查亮度顺序，选择顺序色图 | 3036 青→浅绿→沙色可作为候选；插值后需检查，不宣称感知均匀 |
| 有意义的低/中/高偏离 | 以真实中点建立发散归一化 | 3030 的玫瑰/白/蓝需匹配数值语义；非对称范围也保持中点定义 |
| 机制图空间/角色 | 淡底色分区，中等色实体，较深轮廓与箭头 | 3033–3035、3045–3048；浅色不能直接当小字颜色 |

3031 的浅蓝/薄荷主要适合面积，深蓝/青绿适合细曲线。3032 的多个近邻淡紫色适合有层级的视觉家族，但不适合八条重叠曲线。3042 的高饱和多色在密集类别中有用途，不能归纳成“科研图一律低饱和”。

对色觉差异和灰度打印进行实际预览；本库色板未被认证为色盲友好。连续色图用亮度曲线辅助检查，重要组别同时用直接标注、点型或线型区分。

## 2. 数据图的版式语法

观察：3031 是九个区域的 3×3 矩阵；3036 列代表方法、行代表原始信号/残差/热图；3037 左数据拟合、右残差；3039 上全局下局部；3041 在构成比上方用窄条展示绝对数量。

建议：让行列位置表达比较关系。相同变量的轴、绘图区宽度和基线对齐。相同量纲且需要比较绝对大小时使用共同范围；3031 各区域 y 轴范围实际不同，若借用其布局要显式保留刻度并说明独立量程，不能声称共享 y 轴。

- 原始值 + 残差：共用 x 对齐，残差区较矮，明确零基线；不要把残差作为另一条同轴曲线。
- 总览 + 局部：用选区框和连接线说明放大关系，标出各自比例尺；新增数据前先验证坐标一致。
- UMAP + 构成比：类别命名和颜色共用；UMAP 无量纲，不能把簇间距离解释为未经证明的生物学差异。
- 热图：色条邻近对应面板，写明单位、变换与范围。只在可比较的数据上共享归一化。3030 左热图有格线，3036 连续热图没有格线；按离散/连续单元选择。
- 环形图：适合 3049 式“总体数量+主要构成”概览；精确比较细小比例可改条形图。不要为模仿外观把所有构成比都改成环图。
- 3032 的花瓣/Venn 风格图可表达集合关系示意，但面积难以精确比较；严格集合交并任务先考虑 UpSet 或明确的交集表。

## 3. 分布、误差与模型的视觉次序

观察：3032 的小提琴内叠加箱体；3030 的柱图叠有少量散点；3031 浅色带在曲线后，黑色点和竖向误差突出观测；3037 黑色模型压在彩色观测之上。

建议：背景/区间 → 数据点 → 模型/汇总 → 注释。点数多时降低点大小/透明度或对点层栅格化，保持文本矢量；点数少时优先展示个体。不要仅因参考图有小提琴就对极小样本估计平滑分布。

区间必须说明 CI、SD、SEM、预测区间或其他定义；透明度不代表置信水平。不同区间叠加后会生成新的混合色，不能靠颜色深浅猜范围。多面板共用说明或图例；数据集/方法、样本量和统计信息来自真实输入。

## 4. 机制图的空间语法

观察：3034 围绕细胞外排标签，用折线引导；3035 用膜轮廓界定核内、胞质与胞外；3033 用三列空间分区展示细胞交互；3038 用左总体、右上下机制；3045/3047 顶部合成，下部作用；3046 顶部总流程、底部三项验证。

建议：先定阅读方向与分区，再绘制实体。分区颜色轻、实体颜色中等、关键作用箭头较深；用轮廓差异与标签共同表达实体身份。分子、细胞、组织、动物等不同尺度通过嵌框或放大连接分隔，而不是在同一尺度下堆叠。

箭头实线、虚线、抑制端点和双向线必须有定义；轮廓引导线不加动作箭头。激活/抑制和机制方向必须由用户资料支持。将颜色语义保持到不同场景：同一材料跨合成、递送与作用三处沿用色彩/形状。

3044、3048 有更写实的植物、材料与动物渲染；3046 更偏扁平图解。按素材与用户偏好选一致画法，不强迫所有图统一成扁平或立体。轻微渐变可以提示组织/体积，但数据柱形不加立体阴影。

## 5. 排版与留白的实现起点

下表是新图可调整的起点，**不是对截图精确测量，也不是现行投稿规范**。如用户给出期刊模板，以模板为准。

| 项目 | 可调整起点 | 用意 |
|---|---|---|
| 单图/宽图 | 约 90 / 180 mm 宽 | 先定最终阅读尺寸，避免缩放后字体过小 |
| 轴标题与正文 | 8 pt | 以最终尺寸评估可读性 |
| 刻度与图例 | 7 pt | 多面板保持一致，密集时先减刻度/拆版 |
| 面板字母 | 10 pt，粗体 | 放在统一左上基线，独立于小标题 |
| 轴线/刻度线 | 0.6 pt | 足够清楚且不压过数据 |
| 数据线 | 1.1–1.5 pt | 深色线比置信带更清晰 |
| 置信带 | alpha 约 0.15–0.30 | 只作区间层，按重叠程度调整 |
| 面板间隔 | 绘图区宽的约 10–18% 起调 | 给轴标题与色条留空间，不机械取固定值 |

字体优先清晰无衬线，如用户环境中可用的 Arial、Helvetica 或 DejaVu Sans；中英混排显式选可用中文字体，检查负号、希腊字母、上下标与斜体物种名。参考图里有衬线文本的示意（3048），不据此把所有图标签改为衬线。

统计图通常白底、有限网格，轴框按任务决定：3036 使用完整框，3037 更简省。统一同一张图中的轴线规则，避免无条件删除所有上/右边框。

截图中的大块白边、底部色卡、圆角海报外框、社交水印、截图裁切痕迹不是科研图设计要素。画面留白应帮助面板分组和标签阅读。
